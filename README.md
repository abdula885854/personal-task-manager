# Personal Task Manager

This project is a simple Python application that helps users manage their tasks.

With this application, users can:

- Add new tasks by entering a title and priority.
- View all the tasks in their list.
- Mark a task as completed.
- Delete tasks they no longer need.
- Exit the program when they finish.

The project also includes input validation to prevent empty task titles and invalid priorities.

# How to run

Run the following command in the terminal:

python src/main.py
